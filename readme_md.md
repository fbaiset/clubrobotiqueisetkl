## 🎯 À propos du projet

Ce site a été conçu pour :
* **Promouvoir le club** auprès des étudiants, partenaires et passionnés de technologie.
* **Mettre en valeur nos projets** (robots autonomes, bras articulés, drones, IoT, etc.).
* **Informer sur les événements** à venir (ateliers, formations, hackathons, compétitions).
* **Faciliter l'adhésion** des nouveaux membres via un formulaire dédié.

---

## ✨ Fonctionnalités

- 🏠 **Page d'accueil :** Présentation du club, de notre mission et nos actualités récentes.
- 🛠️ **Showcase des Projets :** Fiches détaillées sur les robots conçus avec photos, vidéos et spécifications techniques.
- 📅 **Calendrier / Événements :** Liste des compétitions à venir et des ateliers de formation (Arduino, Raspberry Pi, Impression 3D, etc.).
- 👥 **L'Équipe :** Présentation du bureau, des membres et des encadrants.
- 📝 **Espace Adhésion / Contact :** Formulaire pour rejoindre le club ou nous poser des questions.
- 🌙 **Mode Sombre / Clair :** Pour une meilleure expérience utilisateur.

## ⚙️ Installation et Lancement

Pour exécuter le projet localement sur votre machine :

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/votre-utilisateur/votre-depot-robotique.git
   cd votre-depot-robotique
   ```

2. **Installer les dépendances (si nécessaire) :**
   ```bash
   npm install
   ```

3. **Lancer le serveur local :**
   ```bash
   npm start
   # ou simplement ouvrir index.html dans votre navigateur
   ```

## 🤝 Contribution

Les contributions de tous les membres du club sont les bienvenues ! Pour contribuer :

1. **Forkez** le projet.
2. Créez votre branche de fonctionnalité (`git checkout -b feature/NomDeLaFeature`).
3. Effectuez vos modifications et **commitez-les** (`git commit -m 'Ajout de la fonction X'`).
4. **Pushez** sur votre branche (`git push origin feature/NomDeLaFeature`).
5. Ouvrez une **Pull Request** pour revue.
